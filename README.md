# CampusCompare — College Discovery Platform

Frontend Engineer internship MVP based on the provided assignment.

## Role / Track
- Role 1: Frontend Engineer
- Track A: College Discovery Platform

## Implemented features
1. College listing + search
2. Filtering and sorting
3. College comparison (up to 3)
4. Predictor tool
5. Saved-college interaction
6. Responsive UI



## Tech
- Next.js 14
- React 18
- TypeScript
- CSS

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Important
The provided internship brief requires the mandatory stack to include Next.js, React, TypeScript and TailwindCSS, with backend/database technologies listed for the overall assignment. This frontend-only version intentionally focuses on Role 1. Before submission, connect the data layer to the employer's expected API/database if required by their review process.

## Demo data
The UI uses a local TypeScript dataset only to make the project immediately runnable. Replace it with API calls before a production submission if the evaluator expects database-backed data.
